# 마크다운 툴바 사용 가이드

[English](README.md)

실리태번 입력창 바로 위에 **서식 버튼 한 줄**을 달아 주는 확장입니다.
`"`, `*`, `**` 같은 기호를 일일이 치지 않고, 버튼 한 번으로 대사·행동·강조를 넣을 수 있어요.
휴대폰에서 특히 편합니다.

---

## 1. 설치하기

1. 실리태번 위쪽의 **확장 프로그램**(퍼즐 모양 아이콘)을 누릅니다.
2. **Install Extension**을 누릅니다.
3. 이 저장소 주소를 붙여 넣고 **Install**을 누릅니다.

설치가 끝나면 입력창 위에 버튼 다섯 개가 생깁니다.

---

## 2. 기본 버튼 다섯 개

| 버튼 | 이름 | 누르면 |
| --- | --- | --- |
| `"` | 대사 | `"안녕"` |
| `*` | 행동/묘사 | `*고개를 끄덕인다*` |
| `**` | 강조/비명 | `**조심해!**` |
| `~~` | 취소선 | `~~없던 일로~~` |
| `>` | OOC/인용 | `> 잠깐 쉬었다 할게요` |

아이콘만 보고 뭔지 모르겠으면 **버튼을 꾹 누르고 있으면** 이름이 뜹니다.

---

## 3. 쓰는 법

### 글자를 골라서 누르기
감싸고 싶은 글자를 드래그로 선택한 뒤 버튼을 누르면 앞뒤에 기호가 붙습니다.

> 고개를 끄덕인다 → 선택 → `*` 버튼 → `*고개를 끄덕인다*`

### 아무것도 안 고르고 누르기
- 커서가 **단어 위**에 있으면 그 단어를 감쌉니다.
- 커서가 **빈 곳**에 있으면 `""`처럼 기호 한 쌍을 넣고, 커서를 그 사이에 둡니다. 바로 이어서 치면 돼요.

### 잘못 눌렀을 때
**같은 버튼을 한 번 더 누르면** 기호가 떨어집니다.

### 이미 보낸 메시지를 고칠 때도 됩니다
메시지 편집창에 커서를 두고 버튼을 누르면, 입력창이 아니라 **그 편집창**에 들어갑니다.
버튼은 항상 "마지막으로 커서가 있던 칸"에 작동해요.

## 4. 설정 열기

**확장 프로그램 → 마크다운 툴바 설정**을 펼치면 됩니다.

| 설정 | 하는 일 |
| --- | --- |
| 마크다운 툴바 활성화 | 툴바 전체를 켜고 끕니다 |
| 글 쓸 때만 보이기 | 평소엔 숨어 있다가 입력창을 누르면 나타납니다. 화면이 좁은 폰에서 추천 |
| 툴바에 보일 버튼 수 | `0`이면 전부 보입니다. 숫자를 넣으면 나머지는 `⋯` 버튼 안으로 들어가요 |

---

## 5. 버튼 고치기

**버튼 목록**에서 줄을 누르면 펼쳐집니다.

- **이름** — 꾹 눌렀을 때 뜨는 이름
- **아이콘 변경** — 아이콘을 목록에서 골라요. 기호를 입력하면 어울리는 아이콘을 알아서 골라 주기도 합니다
- **아이콘 대신** — 여기에 `💬`나 `대사` 같은 글자를 넣으면 아이콘 대신 그게 버튼에 보여요
- **넣는 방식** — 아래 표 참고
- **삽입할 기호** — 실제로 들어갈 기호
- **이렇게 입력돼요** — 결과 미리보기. `|`는 입력한 뒤 커서가 놓이는 자리예요

### 넣는 방식 세 가지

| 넣는 방식 | 이럴 때 | 예 |
| --- | --- | --- |
| 글자 앞뒤에 넣기 | 짝이 있는 기호 | `"대사"`, `**강조**` |
| 현재 줄 맨 앞에 넣기 | 지금 줄을 인용·목록·제목으로 | `> `, `- `, `# ` |
| 다음 줄 맨 앞에 넣기 | 줄을 새로 열고 따로 쓸 때 | OOC 메모, 장면 전환 `---` |

> 💡 기호를 비워 둔 버튼은 아무 일도 안 하므로 목록에 표시되고 툴바에는 안 나옵니다.

> 💡 여러 줄짜리 기호(코드 블록, 표 등)를 넣고 싶으면 줄바꿈 자리에 `\n`을 적으세요.

### 순서 바꾸기
- 줄 왼쪽 **손잡이를 끌어서** 옮기거나,
- 줄을 펼쳐 **맨 위로 / 위로 / 아래로 / 맨 아래로**를 누르세요. 폰에서는 이쪽이 편해요.

### 끄기 · 복제 · 삭제
- **이 버튼 사용** 체크를 끄면 지우지 않고 잠깐 숨길 수 있어요.
- **복제**를 누르면 바로 아래에 복사본이 생깁니다. 비슷한 버튼을 만들 때 편해요.
- **삭제**했어도 잠깐 뜨는 알림을 **누르면 되돌릴 수** 있어요.

---

## 6. 새 버튼 만들기

### 직접 만들기
**+ 새 버튼 추가**를 누르고 이름·넣는 방식·기호를 채우면 끝.

### 준비된 버튼 고르기
**자주 쓰는 버튼 고르기**를 누르면 롤플레이에서 자주 쓰는 버튼이 나옵니다.
원하는 걸 체크하고 **선택한 버튼 추가**를 누르세요.

강한 강조 `***…***` · OOC 메모 `(OOC: )` · 밑줄 · 상태창 · 글머리 목록 · 장면 전환 `---` ·
내 이름 `{{user}}` · 상대 이름 `{{char}}` · 주사위 굴리기 `{{roll:d20}}`

### 처음 상태로 돌리기
**기본 버튼 불러오기**를 누르면 처음 다섯 개로 돌아갑니다.
직접 만든 버튼은 사라지지만, 뜨는 알림을 누르면 되돌릴 수 있어요.

---

## 7. 버튼 세트 공유하기

- **내보내기** — 지금 버튼들을 `.json` 파일로 저장합니다.
- **가져오기** — 다른 사람이 만든 파일을 불러옵니다. 불러올 때
  **목록 전부 바꾸기**와 **목록 뒤에 추가** 중에서 고를 수 있어요.
  전부 바꿨다가 마음이 바뀌면 알림을 눌러 되돌리면 됩니다.

남의 파일을 가져와도 안전합니다. 글자로만 읽고, 스크립트나 외부 이미지는 절대 실행하지 않아요.

## 8. 자주 묻는 질문

**Q. 버튼이 안 보여요.**
설정에서 **마크다운 툴바 활성화**가 켜져 있는지 보세요.
**글 쓸 때만 보이기**가 켜져 있다면 입력창을 한 번 눌러야 나타납니다.

**Q. 버튼을 눌렀는데 아무 일도 안 일어나요.**
그 버튼의 **삽입할 기호**가 비어 있지 않은지 확인하세요.

**Q. `---`를 넣었더니 윗줄이 제목처럼 커졌어요.**
마크다운에서는 `---` 바로 위에 빈 줄이 없으면 윗줄을 제목으로 읽습니다.
**다음 줄 맨 앞에 넣기** 방식을 쓰고, 기호를 `\n---\n`처럼 앞뒤에 줄바꿈을 넣어 주세요.
준비된 **장면 전환** 버튼은 이미 그렇게 되어 있어요.

**Q. 버튼이 너무 많아서 줄이 넘쳐요.**
**툴바에 보일 버튼 수**에 `5` 같은 숫자를 넣으면 나머지는 `⋯` 안으로 들어갑니다.

**Q. 다른 기기에서도 설정이 그대로인가요?**
설정은 실리태번 자체 설정 파일에 저장되므로 같은 계정(프로필)이면 따라옵니다.

## 9. 모양 바꾸기 (선택)

툴바의 위치, 간격, 크기는 **CSS 변수**로 열어 두었습니다.
확장의 CSS를 직접 덮어쓸 필요 없이 **사용자 설정 → Custom CSS**에 값 몇 줄만 넣으면 됩니다.

### 이렇게 넣으세요

`:root { }` 안에 바꾸고 싶은 줄만 적습니다. 나머지는 기본값 그대로 남아요.

```css
:root {
    --qsg-toolbar-justify: flex-start; /* 버튼을 왼쪽으로 붙이기 */
    --qsg-toolbar-gap: 10px;           /* 버튼 사이 간격 */
    --qsg-icon-size: 20px;             /* 아이콘 크기 */
}
```

> 💡 `!important`는 필요 없습니다. 확장 기본값은 우선순위가 낮게 들어가 있어서, Custom CSS에 적은 값이 항상 이깁니다.

### 바꿀 수 있는 값

| 변수 | 기본값 | 하는 일 |
| --- | --- | --- |
| `--qsg-toolbar-order` | `20` | 툴바 위치. 입력창 줄이 `25`라서 `30`을 넣으면 툴바가 **입력창 아래로** 내려갑니다 |
| `--qsg-toolbar-justify` | `center` | 버튼 정렬. `flex-start`(왼쪽), `flex-end`(오른쪽), `space-between`(양끝으로 펼치기) 등 |
| `--qsg-toolbar-gap` | `6px`, 터치 기기 `8px` | 버튼 사이 간격 |
| `--qsg-toolbar-padding` | `0 10px` | 툴바 안쪽 여백 (위아래 / 좌우) |
| `--qsg-toolbar-margin` | `0 0 3px`, 터치 기기 `0 0 5px` | 툴바 바깥 여백. 세 번째 값이 입력창과의 간격 |
| `--qsg-button-padding` | `3px 8px` | 버튼 안쪽 여백. 첫 값을 키우면 **버튼이 높아져서** 누르기 쉬워집니다 |
| `--qsg-button-min-width` | 아이콘 크기 + 18px | 버튼 최소 너비. 아이콘 버튼들의 너비를 고르게 맞춰 줍니다 |
| `--qsg-button-max-width` | `140px` | 버튼 최대 너비. 긴 글자 라벨이 줄을 다 차지하지 않게 막아 줍니다 |
| `--qsg-overflow-max-width` | `min(90vw, 320px)` | `⋯` 메뉴가 이 폭을 넘으면 두 줄로 접힙니다 |
| `--qsg-icon-size` | `16px` | 아이콘 크기. 버튼 최소 너비도 이 값에 맞춰 같이 커집니다 |

> 💡 **터치 기기**(폰, 태블릿)에서는 잘못 누르는 일을 줄이려고 간격과 여백을 조금 더 벌려 둡니다.
> 위 표에서 기본값이 두 개인 항목이 그렇습니다. 직접 값을 적으면 PC와 폰 모두 그 값으로 통일돼요.

### 따라 해 보기

**폰에서 버튼을 크게**

```css
:root {
    --qsg-button-padding: 8px 12px;
    --qsg-icon-size: 20px;
    --qsg-toolbar-gap: 10px;
}
```

**툴바를 입력창 아래로, 왼쪽 정렬**

```css
:root {
    --qsg-toolbar-order: 30;
    --qsg-toolbar-justify: flex-start;
    --qsg-toolbar-margin: 3px 0 0; /* 이제 위쪽이 입력창이니 여백도 위로 */
}
```

**PC에서만 바꾸고 폰은 그대로**

```css
@media (pointer: fine) {
    :root {
        --qsg-icon-size: 14px;
        --qsg-toolbar-gap: 4px;
    }
}
```

### 버튼 하나만 꾸미고 싶을 때

**몇 번째 버튼인지**로 고르는 게 가장 확실합니다.

```css
/* 다섯 번째 버튼(기본 설정이면 OOC/인용)만 색 바꾸기 */
#custom-md-toolbar button:nth-child(5) {
    color: var(--SmartThemeQuoteColor);
}
```

버튼 **이름**으로도 고를 수 있지만, **내 설정에 적힌 이름과 정확히 같아야** 합니다.

```css
#custom-md-toolbar button[title="대사"] {
    color: var(--SmartThemeQuoteColor);
}
```

> ⚠️ 기본 버튼 이름은 **처음 만들어질 때의 실리태번 언어**로 저장됩니다.
> 한국어로 설치했다면 `OOC/인용`, 영어로 설치했다면 `OOC / Quote`예요.
> 남에게 받은 CSS가 안 먹으면 이름이 다른 경우가 많으니, 버튼 목록에서 이름을 확인하거나 `nth-child`를 쓰세요.

### 그 밖에 쓸 수 있는 선택자

변수로 안 되는 건 아래 이름으로 직접 꾸밀 수 있습니다. 이 이름들은 앞으로도 바꾸지 않습니다.

| 선택자 | 가리키는 것 |
| --- | --- |
| `#custom-md-toolbar` | 툴바 한 줄 전체 |
| `#custom-md-toolbar button` | 툴바의 모든 버튼 |
| `.qsg-overflow-trigger` | `⋯` 버튼 |
| `.qsg-overflow-menu` | `⋯`을 누르면 뜨는 메뉴 |
| `.qsg-overflow-wrapper` | `⋯` 버튼과 메뉴를 감싸는 틀 |
| `#custom_md_buttons_container` | 확장 프로그램 패널 안의 설정 영역 |
| `.qsg-item` | 버튼 목록의 한 줄 |
| `.qsg-item-disabled` | 사용을 꺼 둔 버튼의 줄 |
| `.qsg-item-blank` | 기호가 비어 있는 버튼의 줄 |

버튼은 실리태번 기본 버튼(`menu_button`)을 그대로 쓰기 때문에, 테마를 바꾸면 툴바도 알아서 따라 바뀝니다.

### 잘 안 될 때

- **바뀌지 않아요** → `:root { }` 안에 넣었는지, 변수 이름 앞의 `--` 두 개와 끝의 `;`를 빠뜨리지 않았는지 확인하세요.
- **폰에서만 안 바뀌어요** → `@media (pointer: fine)`처럼 PC 전용 조건 안에 넣지 않았는지 보세요.
- **원래대로 돌리고 싶어요** → Custom CSS에서 그 줄을 지우면 기본값으로 돌아갑니다.
